A. Identitas Produk Perangkat Lunak
1. Nama Aplikasi / Software: GnR PetHouse
2. Kategori Produk: Aplikasi Kasir dan Manajemen Stok Pet Shop Berbasis Android.
3. Deskripsi Singkat Fungsi Aplikasi:
GnR PetHouse adalah aplikasi digital yang dirancang untuk membantu pemilik toko
hewan peliharaan dalam pencatatan transaksi penjualan makanan dan perlengkapan
hewan, pengelolaan stok barang, serta pencatatan data pelanggan secara praktis.
